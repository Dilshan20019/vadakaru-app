# Vadakaru Mobile App

A modern React Native application built with **Expo**, **TypeScript**, and clean architecture.

## 🚀 Features

- **Authentication Flow**:
  - **Login Screen**:
    - Email & password validation
    - Password visibility toggle (show/hide)
    - "Remember Me" toggle
    - "Forgot Password" action
    - One-tap Quick Demo credentials auto-fill
    - Social sign-in options (Google, Apple, GitHub)
  - **Register Screen**:
    - Full name, email, password, and confirm password fields
    - Terms & privacy policy acceptance toggle
    - Real-time inline field validation
  - **Home / Dashboard Screen**:
    - Personalized greeting & avatar
    - Active session status & security badges
    - Quick account shortcuts
    - Sign out confirmation modal

## 🛠️ Running the Application

Ensure dependencies are installed:
```bash
npm install
```

Start the Expo development server:
```bash
npm start
# or
npx expo start
```

### Previewing the App:
- **Expo Go (iOS / Android)**: Scan the QR code shown in the terminal with the Expo Go app.
- **Android Emulator**: Press `a` in the terminal.
- **iOS Simulator**: Press `i` in the terminal.
- **Web Browser**: Press `w` in the terminal (or run `npm run web`).
